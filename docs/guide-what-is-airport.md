# 机场是什么｜机场订阅、节点与客户端入门

[机场推荐首页](../README.md) · [全部机场测评](airports.md) · [内容导航](README.md)

在本文的语境里，机场是提供代理节点及订阅管理的网络服务。你购买套餐后，通常需要把订阅导入兼容客户端，选择节点使用。不同机场的客户端、协议和付款方式可能不同，不能默认都支持同一种导入方法。

## 从注册到使用，分别涉及什么

| 名称 | 主要作用 | 要注意什么 |
|---|---|---|
| 机场账号 | 管理套餐、订单、流量与订阅 | 保存邮箱、密码和官方通知渠道 |
| 套餐 | 规定流量、周期、设备与节点权限 | 同名套餐不同周期也可能有权限差别 |
| 订阅链接 | 让客户端获取可用节点及配置 | 链接可能包含凭据，不要公开分享 |
| 客户端 | 在设备上导入配置并连接节点 | 软件支持的协议和内核版本要匹配 |
| 节点 | 具体可连接的服务器与路线 | 同一机场的不同地区也可能差异明显 |

## 机场推荐应该先比较什么

先确认自己需要的地区、客户端和月度用量，再看月付或按量方案。例如：[Flybit](airport-flybit.md)有月付与不限时包；[西游云](airport-xiyou.md)适合比较低月费；[飞鸟云](airport-feiniaoyun.md)有IPv6配置门槛，不宜只按价格判断。

## 第一次购买的四步

1. 列出常用设备、平台与地区。
2. 核对客户端支持与套餐权限。
3. 选择金额可接受的短周期或小额套餐。
4. 导入后记录白天、晚高峰和不同网络下的实际体验。
