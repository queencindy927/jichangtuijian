# 机场订阅怎么用｜客户端选择与导入检查清单

[机场推荐首页](../README.md) · [机场测评目录](airports.md) · [内容导航](README.md)

购买机场套餐后，通常需要在会员中心获取订阅，再导入兼容客户端。本页提供通用检查步骤；每家机场实际提供的格式、协议和客户端可能不同，应先按官方教程操作。

## 第一步：确认客户端能配合机场

| 要确认什么 | 为什么要确认 |
|---|---|
| 操作系统 | 手机、电脑、路由器可能使用不同软件 |
| 协议与内核 | 同名客户端不同版本支持范围可能不同 |
| 订阅格式 | 不同客户端可能需要不同导入入口 |
| 服务方限制 | 并非所有机场都支持所有第三方客户端 |

[飞鸟云](airport-feiniaoyun.md)需核对Hysteria2与IPv6；其他机场也要逐项确认，不能用“都能导入Clash”概括全部服务。

## 第二步：导入与更新

1. 登录会员中心，找到对应设备的使用教程。
2. 从可信官方发布渠道获取客户端。
3. 选择与客户端匹配的订阅格式，使用服务方提供的导入方式。
4. 在客户端更新订阅，确认节点列表正常出现。
5. 选择适用节点，检查连接与常用应用。

## 第三步：确认流量与模式

检查客户端规则、所需系统权限、应用代理范围和节点倍率。首次使用后查看后台流量扣除，确认没有大量后台更新或其他应用占用额度。

## 订阅为什么需要保密

订阅链接可能包含账号相关凭据，分享后可能被他人使用。公开截图时遮住链接、二维码和账号信息；怀疑泄露时，在后台重置订阅并更新自己的设备。

## 导入后没有节点怎么办

先看套餐是否有效、订阅是否更新成功、链接格式是否对应客户端，再按[故障排查指南](guide-troubleshooting.md)逐项检查。不要把订阅完整链接粘贴到公开提问中。
