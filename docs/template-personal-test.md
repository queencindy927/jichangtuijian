## 如何写结论

- 写清自己测过的条件，不把个人网络结果扩大成所有地区保证。
- 有具体数据时记录工具和单位，区别MB/s与Mbps。
- 将服务方宣传配置与自己观察到的现象分开。
- 失败结果也保留，不只选择最快一次。
- 当前无法确认的事项留空或标注待确认。
