本版本将“机场推荐”作为筛选入口，将“机场测评”用于套餐、配置与限制分析。内容基于项目已有资料整理，没有新增统一网络测速，不把历史延迟、在线率或速度截图当作当前使用保证。

## 资料和结论怎么区分

| 类型 | 本版本如何处理 |
|---|---|
| 套餐文字 | 按原周期、流量与权限整理，明确月付、季付、年付和一次性总量 |
| 服务方能力说明 | 写明“资料提及”或“套餐标注”，不转换成全部节点长期保证 |
| 计算 | 极速云倍率折算等为算术估算，保留输入条件 |
| 推荐判断 | 围绕预算、设备、用途和门槛给建议，不冒充实测速率排序 |
| 不完整信息 | 标注未收录、待确认或保留原始周期，不补写价格与节点权限 |

## 推荐顺序怎么确定

本篇固定为：Flybit、西游云、CocoDuck、星辰云、飞鸟加速、飞鸟云、秒秒云、WgetCloud、极速云、魔戒、大哥云、扬帆云。

该顺序由维护者指定，只用于本版本的内容编排。没有统一benchmark，不根据套餐单价、线路名称或本文更新自动计算名次，也不修改主网站或其他文章版本的评分与排序。

## 场景推荐怎么使用

- 性价比：Flybit或西游云。
- 便宜量大：西游云或星辰云。
- 高端场景：CocoDuck或WgetCloud。
- 按量付费：Flybit。

同一分类列出的机场是备选，按自己需求选择；同一家出现在多个分类不表示要多次注册或购买。

## 几处需要额外注意的资料

- 飞鸟加速与飞鸟云分开记录，前者后附的旧介绍不直接用作当前规格。
- 极速云按6倍倍率折算是计算示例，使用时看当前所选节点倍率。
- CocoDuck加油包依附常规套餐，不计入独立按量起步价。
- 魔戒1GB小额体验不计作常规按量起步价。
- 扬帆云概况与套餐的专线命名有差别，保留待核对信息，不合并成确定结论。
- WgetCloud在线IP与连接数保留原单位，不改写为同等设备数。
